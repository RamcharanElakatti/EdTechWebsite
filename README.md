# EdTech Website

A multi-page EdTech website built with React and Vite. The site presents online learning programs, bootcamps, pricing, mentors, success stories, events, career services, admissions, scholarships, enterprise training, and support pages for learners.

## About the Project

This project is a front-end website for an education technology platform. It uses hash-based navigation to move between pages without a backend server or routing package. The content is organized around career-focused programs such as Frontend Engineering, Full Stack Development, Data Analytics, UI/UX Design, AI Engineering, and Cybersecurity.

## Features


- Course catalog and individual program pages
- Bootcamp, pricing, admissions, and scholarship pages
- Mentor profiles and learner success stories
- Career services, hiring partners, community, events, blog, and help center pages
- Responsive React component structure
- Static data-driven content from `src/data/siteData.js`

## Tech Stack

- React
- Vite
- JavaScript
- JSX
- CSS
- React DOM

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Project Structure

```text
src/
  components/    Reusable layout and UI components
  data/          Shared site content and route data
  pages/         Individual website pages
  App.jsx        Main app and hash-based route selection
  main.jsx       React entry point
```
